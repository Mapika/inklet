# V2 compilation contract

The compiler retains the existing geometry, shaping, layout and routing code.
Its new responsibility is evaluating live definitions consistently.

1. **Dependency resolution.** Specs hold snapshotted literal arguments and
   explicit live references. Dataset revisions and file content hashes
   invalidate dependent recipes. Cycles fail before recursive rendering.
2. **Measurement.** Factories execute under a context-local theme. Text is
   shaped at its final physical size. Plots are measured with axes, keys,
   annotations, insets and titles.
3. **Track allocation.** Contiguous span constraints use prefix-sum longest
   paths for an exact minimum-size feasibility bound. Dykstra projections find
   a feasible allocation close to the requested track weights. This allows
   overlapping spans in different rows to share a constrained middle track.
4. **Plot fitting.** Measured furniture margins are shared across compatible
   rows and columns. Plots rebuild at the remaining data-region size. Margins
   grow monotonically to prevent tick-selection oscillations; convergence is
   checked within 0.005 mm, with a bounded number of passes.
5. **Placement and routing.** Each cell receives an independent copy of its
   drawing. Named connections route after placements settle. Final node IDs
   follow semantic cell names and tree positions rather than allocation order.
6. **Paint and validation.** Inherited paint becomes explicit in one resolved
   tree consumed by SVG and PDF. Transforms, clipping and opacity groups remain
   structural. Diagnostics run on this same tree. A compiled snapshot owns its
   resolved page, cell map, diagnostics, provenance and build statistics.

Caches are document-local and bounded to 512 recipe/dimension/theme entries.
Author functions must be deterministic and must declare changing inputs as
arguments. Direct mutation inside arbitrary closure state is outside the cache
contract. File references are explicit so compiling a document does not scan
unrelated directories.

Legacy drawings remain fixed geometry. A live legacy Panel invalidates a
document when its built drawing changes, but its old drawing instructions are
not recovered or resized. Use PlotSpec to make scales and furniture responsive.

The CLI uses fresh processes for watched builds, including imported helper code.
Only successful exports replace existing bundle files. The local server reports
build errors separately from the last successful figure.
