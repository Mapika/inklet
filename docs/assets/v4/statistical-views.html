Original simulated cycle times by Mark Marosi · MIT material. The ranges are illustrative supplied bounds, not confidence intervals. ECDFs describe nonmissing source estimates in each process; filtering hides markers only. Python measured the axes and outlined text. This prototype renders circles, line segments, bars and polygon regions with fixed page geometry, clips them to their plot areas and preserves row identity. Page zoom moves the whole drawing; it does not recalculate domains or ticks. Data and runtime are embedded for offline use.
