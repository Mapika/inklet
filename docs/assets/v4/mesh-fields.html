Source observations


Simulated triangular surface and supplied face fields by Mark Marosi · MIT. No simulation or interpolation is performed. Plan colors are constant per face; arrows show XY components with 0.22 mm of geometry per vector unit. The scatter uses full XYZ magnitude. The fixed-camera 3D panel is an unpickable reference and stays visible during filtering. Plan triangles, arrows and scatter points follow face visibility. Geometry is in mm; field units are arbitrary. Python measured the axes and outlined text. This prototype renders circles, line segments, bars and polygon regions with fixed page geometry, clips them to their plot areas and preserves row identity. Page zoom moves the whole drawing; it does not recalculate domains or ticks. Data and runtime are embedded for offline use.
