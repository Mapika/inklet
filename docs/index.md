## Reference and development

Use the [Python API](api.md) for signatures, the [command-line reference](cli.md)
for script workflows and [troubleshooting](troubleshooting.md) for diagnostics.
[Migration](migration.md) covers existing projects.

Core guides work with the stable release. Features marked **preview** require
[the development installation](development-preview.md). Engine studies and
historical designs are grouped under Development; see the [4.0 roadmap](roadmap.md)
and [contributing guide](../CONTRIBUTING.md) to follow or contribute to that work.
