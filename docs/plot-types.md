# Choose a plot type

Choose a preview to open its runnable Python code and input conventions.
These illustrative examples use core Inklet. Each image is generated from the
code in its guide.

For input choices and interpretation, see [Select a mark](plotting.md#select-a-mark).

Each card represents a distinct visual choice. The guides also cover variations
such as [single-series bars](bars-and-areas.md#categorical-bars),
[custom glyphs](lines-and-points.md#custom-markers) and
[a line with error magnitudes](uncertainty.md#line-with-errors).

For mixed figures, [combine plot layers](plotting.md) and
[arrange panels](layout.md). The gallery below links to complete examples;
[dense data](dense-data.md) explains rendering choices for larger inputs.

Browse [lines and points](lines-and-points.md), [bars and areas](bars-and-areas.md),
[distributions](distributions.md), [uncertainty](uncertainty.md),
[matrices](matrices.md) or [polar plots](polar-plots.md).
